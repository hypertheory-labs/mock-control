## Chose: Pin MSW 2 in the install step, rather than support MSW 3
- where: `projects/mock-control/README.md › mock-control › Setup › 1. Install`
- quote: `npm install -D @hypertheory-labs/mock-control msw@2 daisyui@5`

**Because (measured, then Claude, not asked):** step 1's plain `msw` installed 3.0.3, now
npm's `latest`. npm allowed it although the package's peer range is `^2.15.0`; only
`npm ls` called it invalid. Step 4's `worker.start({ onUnhandledRequest })` then fails
to compile. The Requirements already said MSW 2; the command didn't. Supporting MSW 3
was the other way out, and I didn't take it: the README's known limits were measured
on 2.15, so a port is its own round with its own measurements, and it should be Jeff's
call whether the class apps move.

## Chose: daisyUI goes in the install step, and Requirements says how Tailwind arrives
- where: `projects/mock-control/README.md › mock-control › Requirements`
- quote: `up Tailwind; daisyUI is installed in step 1.`

**Because (measured):** `ng new --style=tailwind` sets up Tailwind v4 but not daisyUI,
and nothing in the README installed it; step 5's `@plugin 'daisyui'` assumed it.

## Chose: Say the example's `catalog` and `findTitle` are the reader's
- where: `projects/mock-control/README.md › mock-control › Setup › 2. Write the handlers`

**Because (measured):** copied as written, step 2 fails with two "Cannot find name"

## Answered: Tailwind finds the panel's classes through the `@source` line
**Answer (measured):** held. In a fresh Angular 22 app with the package installed from
`npm pack` of `dist/mock-control`, six classes only the panel uses (`modal-end`,
`tabs-border`, `badge-warning`, `btn-circle`, `tab-active`, `modal-box`) are all in the
built CSS with the line, and none are without it (121 KB against 28 KB). Repeated in a
second fresh app following the fixed README. Not checked: how it looks in a browser.
The CSS is the evidence; nobody has seen the panel render outside this workspace yet.
This also answers pumice's guess, and clears what pumice said publishing waits on.

## Answered: The README's setup works without knowing anything it doesn't say
**Answer (measured):** disproved, at step 1, and twice more. MSW 3 broke step 4,
daisyUI was never installed, and the handler example didn't compile as written. Each is
fixed in the README, and the fixed steps build in a second fresh app, in development
and production. One thing I still had to know: `ng new --style=tailwind`. The README
now says it, but whether a reader who doesn't know Angular's options needs more is a
question only a reader can answer.
